⚡ Kimbal Urja — Lead Tracker Setup

Connect to Google Sheets so your whole team can view and update leads live. Takes ~5 minutes.

1

Create a blank Google Sheet

Go to sheets.google.com → Blank. Name it "Kimbal Urja Leads".

2

Open Apps Script

In your Sheet: Extensions → Apps Script.

3

Paste the backend code

Delete all existing code, paste everything from Apps_Script_Backend.gs (same folder as this file). Save.

4

Deploy as Web App

Deploy → New deployment → Web App
• Execute as: Me · Who has access: Anyone
Click Deploy → copy the Web App URL.

5

Paste your URL here

🔒 Data stays in your Google Sheet. Share this HTML file with your team — everyone uses the same URL to get live shared data.
